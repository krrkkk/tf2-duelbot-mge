# mgebot duel companion 0.3.7

[English](README.md) · [Изменения](CHANGELOG.ru.md) · [Discord: установка, обновления и поддержка](https://discord.gg/GGMz952jBA)

Приложение для Windows: тренировки TF2 с ботами, дуэли 1v1, локальный 2v2, настройки ботов и сохранённые пресеты. В комплекте плагин **5.3.1**, карта Triumph, модели движения и русский/английский интерфейс.

## Начать игру

1. Установи TF2 через Steam. Перед установкой или обновлением компонентов закрой игру.
2. Распакуй **целиком** `mgebot_duel_companion_0.3.7_Windows_x64.zip` и запусти `mgebot-duel.exe`. Папки рядом с ним нужны для работы.
3. Если папка TF2 не определилась, выбери её вручную и нажми **Установить**. При первой установке приложение скачивает закреплённые версии MetaMod и SourceMod.
4. Выбери **1v1** или **2v2**, арену и настройки ботов, затем запускай игру.

Для обновления распакуй приложение в новую папку и обнови игровые компоненты при закрытой TF2. Пресеты, базы игроков и пользовательская разметка арен сохраняются. Отдельно устанавливать Python для готового приложения не нужно.

Для тренировки запускай TF2 через приложение. Перед игрой на обычных серверах выйди из TF2 и запусти её через Steam.

## 2v2

Приложение создаёт сервер на твоём компьютере через Steam Networking. По умолчанию доступ открыт **только друзьям**; до запуска можно выбрать другие варианты видимости. Пригласи друга через Steam. Ему нужна та же карта Triumph; после подключения он вводит `!add`, выбирает 2v2 и твою арену. Для занятой арены есть очередь.

Через **Добавить бота-напарника** можно играть вдвоём с ботом против двух ботов. Доступны скаут, солдат и демоман, без повторения класса внутри команды. Классы ботов случайные. Очко начисляется за уничтожение обоих соперников; все возрождаются вместе перед следующим раундом. Игра до **20 побед в раундах**. Пока ты хостишь, TF2 должна оставаться открытой.

## Тренировка

Тактика, shotgun deny, смена оружия и Gunboats находятся прямо в настройке бота. В дополнительных настройках — задержка реакции, движение, защита после появления и другие правила тренировки. Классический Ammomod: стартовые 300 HP и конечные патроны. Оригинальный звук возрождения MGE включается отдельно. Сохраняй пресеты; для изменения текущей игры нажимай **Применить**.

В приложении нет входа оператора, отправки скриншотов и журнала правок. Alt+Shift+A не назначена. Диагностика сбоев остаётся локальной: **Настройки → Журнал сбоев TF2** открывает папку; приложение не отправляет отчёты и дампы автоматически. Пресеты и данные подключения к игре хранятся на твоём компьютере.

## Особенности выпуска

- Приложение только для Windows x64. Для Linux есть отдельный архив **Linux Dedicated** с плагином для собственного выделенного TF2-сервера.
- В локальной Windows-сборке команда `!hop` недоступна.
- Работу в настоящей игре, включая 2v2 с другом, ещё нужно проверить. Известные сбои Windows описаны в отчёте о подготовке релиза.

## Исходники и сборка

Архив исходников содержит приложение и инструменты сборки. SourcePawn ботов и личные данные в него не входят. См. [лицензию](LICENSE) и [зависимости](THIRD_PARTY.md).

Установи Python 3.13 и зависимости из `requirements.txt`, затем выполни:

```sh
python run.py --payload /path/to/mgebot_duel_5.3.1_Windows_x64.zip
```

Для Windows-сборки нужны MinGW-w64 с `gcc` и `windres`:

```sh
python scripts/build.py --platform windows --out build/windows --cache build/cache --payload /path/to/mgebot_duel_5.3.1_Windows_x64.zip
python scripts/package.py --out dist --build build/windows
```

Сборка проверяет закреплённые загрузки из `build-lock.json`; упаковка фиксирует хеши и сверяет исходники с приложением. Контрольные суммы файлов релиза находятся в `SHA256SUMS.txt`.
